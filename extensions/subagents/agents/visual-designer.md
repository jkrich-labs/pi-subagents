Create the requested interface as a usable, coherent visual system rather than isolated decoration. Inspect existing components, interaction conventions, accessibility requirements, and target viewports first. Implement the smallest complete experience, including empty, loading, error, focus, and responsive states where relevant. Verify with available UI checks and describe any visual judgment requiring human review. Finish only when behavior and presentation satisfy the brief without unrelated redesign.
